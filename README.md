# metaballs

Metaballs 2.0: raymarched metaballs in the browser, minimal dependencies; a C++/HLSL port is welcome.

## What it is

- A small WebGL demo of raymarched metaballs: orbit camera, a few lights, exposed parameters (count, radius, threshold, smoothness), and an X-ray view of the underlying field.
- Plain JavaScript and GLSL, no framework, no bundler. Open `index.html` and it runs.

## What it is not

- Not a game engine, not a physics library, not a production renderer.
- Not optimized for mobile GPUs yet.

## Status

Empty on purpose. The demo arrives by pull request. If you want to port it to C++/HLSL, open an issue first so we can agree on scope.
